一、产品背景
这是一个叫**“AI画画”**的小程序。
用户可以：
• 用文字描述生成AI图片
• 浏览所有人发布的作品
• 管理自己创作的画作
￼
二、整体结构
底部固定Tab栏：
css
复制代码
[ 首页 ]    [ 我的 ]
￼
三、页面一：首页（AI画作广场）
页面目标
让用户一打开就看到大量AI画作，并被吸引去创作。
页面布局（从上到下）
1. 顶部栏
• 居中标题：AI画画
• 无返回按钮
2. 瀑布流画作列表
• 双列卡片流
• 每个卡片包含：
• 图片缩略图（主视觉）
• 作者昵称（小字）
• 点赞数（右下角小图标）
3. 悬浮按钮
• 页面右下角固定“+”号圆形按钮
• 点击 → 跳转【创建图片】页面
4. 滚动规则
• 向下滑动自动加载更多作品
• 新发布的作品显示在最上方
￼
四、页面二：创建图片（画画页）
页面目标
让用户只用一句话就能生成一张画。
页面布局
1. 提示词输入框
• 占位提示：请输入你想画的画面描述
• 示例：夕阳下的赛博城市，霓虹灯，未来风
2. 生成按钮
• 主按钮：生成图片
3. 加载状态
• 居中加载动画
• 文案：AI正在作画中…
4. 生成结果区
• 大图预览
• 下方显示：提示词文本
• 下方按钮：发布
￼
五、页面三：我的
页面目标
管理用户自己的作品。
页面布局
1. 用户信息区
• 头像（圆形）
• 微信昵称
2. 未登录状态
• 显示：微信一键登录按钮
3. 已登录状态
• 显示“个人画廊”标题
4. 画作网格
• 三列小图网格
• 点击可放大查看
￼
六、发布逻辑说明（用于原型备注）
• 用户点击【发布】
• 系统保存图片+提示词+作者
• 自动跳回首页
• 新图显示在最上方
￼
